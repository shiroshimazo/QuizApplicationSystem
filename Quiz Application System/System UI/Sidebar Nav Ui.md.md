# Sidebar Navigation Panel

The Sidebar Navigation Panel serves as the main navigation area after user login.

The system consists of three user panels:

## 1. Administrator Panel

### Navigation Menu:
- Dashboard
- Student Management
- Teacher Management
- Quiz Management
- Subject/Category Management
- Reports
- Results
- Account Management
- Logout

### Panel Size:
- **1180x700 pixels**

---

## 2. Teacher Panel

### Navigation Menu:
- Dashboard
- Create Quiz
- Manage Questions
- Assigned Subjects
- Student Results
- Quiz Statistics
- Logout

### Panel Size:
- **1180x700 pixels**

---

## 3. Student Panel

### Navigation Menu:
- Dashboard
- Available Quizzes
- Take Quiz
- Quiz Results
- Profile
- Logout

### Panel Size:
- **1180x700 pixels**
